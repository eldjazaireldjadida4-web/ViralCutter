## لماذا ViralCutter "يغيّر قواعد اللعبة"؟

انسَ الاشتراكات الغالية وحدود الدقائق. ViralCutter يعطيك قوة غير محدودة على جهازك أنت.

| الميزة | ViralCutter (مفتوح المصدر) | Opus Clip / Klap / Munch (خدمات سحابية) |
| :--- | :--- | :--- |
| **السعر** | **مجاني وبلا حدود** | $20–$100 شهرياً + حدود دقائق |
| **الخصوصية** | **محلي 100%** (بياناتك لا تغادر جهازك) | رفع لسيرفرات طرف ثالث |
| **الذكاء الاصطناعي** | **مرن**: Gemini (مجاني)، GPT-4، **GGUF محلي (أوفلاين)** | ما يقدمونه هم فقط |
| **تتبع الوجه** | **شاشة مقسمة (وجهان)**، متحدث نشط (تجريبي)، تلقائي | أساسي أو مدفوع إضافي |
| **الترجمة** | **نعم** (ترجم لأكثر من 10 لغات) | إمكانيات محدودة |
| **التحرير** | **تصدير XML لـ Premiere Pro** (تجريبي) | محرر ويب محدود |
| **العلامة المائية** | **صفر** | موجودة (في الخطط المجانية) |

**نتائج احترافية، خصوصية كاملة، وتكلفة صفر.**

## الميزات الرئيسية 🚀

- 🤖 **قص فيروسي بالذكاء الاصطناعي**: يحدد تلقائياً الخطافات (hooks) وأكثر اللحظات تفاعلاً باستخدام **Gemini** أو **GPT-4** أو **نماذج محلية (Llama 3، DeepSeek، إلخ)**.
- 🛡️ **فلتر الأمان ضد مخالفات يوتيوب (جديد!)**: يفحص نص كل مقطع مقترح و**يمنع تلقائياً** المقاطع التي تحتوي على **الكلام الذي يحضّ على الكراهية** — إما بحذف المقطع أو **بكتم الكلمة المخالفة فقط (Bleep)** مع الإبقاء على المقطع. طبقة إضافية بمراجعة سياقية عبر الذكاء الاصطناعي + تقرير `safety_report.json` لكل مشروع.
- 🗣️ **نسخ صوتي فائق الدقة**: مبني على **WhisperX** مع تسريع GPU لترجمات مثالية التوقيت.
- 🎨 **ترجمات ديناميكية**: بأسلوب "Hormozi" مع تمييز كلمة بكلمة، ألوان نابضة، وتخصيص كامل (خط، لون، إطار، ظل).
- 🎥 **إخراج كاميرا تلقائي**:
  - **قص تلقائي 9:16**: يحوّل الأفقي إلى عمودي مع الحفاظ على التركيز.
  - **شاشة مقسمة ذكية**: يكتشف شخصين يتحدثان ويقسم الشاشة تلقائياً.
  - **المتحدث النشط (تجريبي)**: الكاميرا تنتقل لمن يتكلم.
- 🌍 **ترجمة الفيديو**: أنشئ ترجمات مترجمة تلقائياً (مثال: فيديو إنجليزي ← ترجمة عربية).
- 💾 **جودة وتحكم**: اختر الدقة (حتى 4K/الأفضل)، نسّق المخرجات، واحفظ إعدادات المعالجة كقوالب.
- ⚡ **الأداء**: نسخ صوتي بتقنية "slicing" (يعالج مرة واحدة، يقص عدة مرات) وتثبيت سريع جداً عبر `uv`.
- 🖥️ **واجهة حديثة**: WebUI بـ Gradio، وضع داكن، معرض مشاريع، ومحرر ترجمات مدمج — **بواجهة عربية كاملة (RTL)**.

## 🛡️ فلتر الأمان (تجنّب مخالفات "الكلام الذي يحضّ على الكراهية")

أكبر سبب لضربات يوتيوب (Strikes) عند نشر المقاطع القصيرة هو مقطع واحد يحتوي على شتيمة أو تحريض. ViralCutter يحميك بثلاث طبقات:

1. **وقاية من المصدر**: البرومبت المُرسل للذكاء الاصطناعي يمنعه صراحةً من اختيار مقاطع فيها خطاب كراهية أو تحريض على العنف.
2. **فلتر الكلمات المحلية قبل القص**: يُفحص نص كل مقطع ضد قائمة محلية متعددة اللغات (عربي فصحى ولهجات، إنجليزي، برتغالي، فرنسي، إسباني، تركي). يفهم التحايل: التشكيل، التطويل (حـــرم)، الأرقام والرموز (@، 3)، و"ال" التعريف الملتصقة.
3. **مراجعة سياقية بالذكاء الاصطناعي (جديد!)**: بعد الفلترة، تُرسل المقاطع الناجية لـ Gemini/G4F بسؤال "هل هذا يخالف سياسة يوتيوب؟" — يكشف الكراهية **السياقية** بدون كلمات محظورة (مثال: "هذه الفئة لا تستحق الوجود"). يعمل تلقائياً ولا يكسر المعالجة عند فشله.

**الأوضاع الأربعة** (من الواجهة أو `--safety-mode`):

| الوضع | السلوك |
| :--- | :--- |
| `block` (افتراضي) | **حذف** المقطع المخالف من قائمة القص نهائياً |
| `censor` 🔇 | **كتم الكلمة المخالفة فقط** (Bleep): يكمّم الصوت في تلك اللحظة + يخفي الكلمة من الترجمة (`████`) — والمقطع الفيروسي يبقى! |
| `flag` | الإبقاء على المقطع مع **وسمه** في التقرير للمراجعة اليدوية |
| `off` | تعطيل الفلتر |

**المخرجات**: 
- `safety_report.json` — حالة كل مقطع: safe/blocked/flagged، الكلمات المطابقة، التصنيف، الخطورة، التوقيت التقريبي + نتائج مراجعة الذكاء الاصطناعي.
- `censor_map.json` (وضع الكتم) — كل كلمة مكتومة وتوقيتها بالضبط.
- تبويب **مراجعة المقاطع** في الواجهة يعرض عمود "الأمان" (✅ / ⚠️ / 🔇 / 🤖⚠️).

**تخصيص القوائم**: انسخ `safety_terms.example.json` إلى `safety_terms.json`:
- `extra_terms` — كلمات إضافية للحظر.
- `allow_terms` — استثناء كلمات من الحظر (لإصلاح الحظر الخاطئ، مثلاً قناة تاريخية تقول "منغولي").

**🔄 تحديث تلقائي لقائمة الكلمات (جديد!)**:
يوتيوب يحدّث سياساته وكلمات التحريض باستمرار — لذلك ViralCutter يتحدّث قائمته بنفسه:
- تُنشر القائمة الرسمية `safety_blocklist.json` في مستودع GitHub، وكل جهاز يسحبها **تلقائياً مرة كل 24 ساعة** أثناء المعالجة (أو زر "🔄 تحديث قائمة كلمات الأمان" في الواجهة).
- **بدون إنترنت؟** لا مشكلة — يبقى على آخر قائمة محفوظة (أو المدمجة) ويستمر العمل.
- أي كلمة جديدة تُضاف للمستودع تصل لجهازك بدون تحديث البرنامج نفسه.
- لإيقاف التحديث التلقائي: `--safety-autoupdate off`.

## 📊 بطاقة المخاطر (Risk Scorecard) — ضد المحتوى المُعاد استخدامه وخسارة الربح

بعد كل معالجة، تُنتج الأداة **تقرير امتثال لكل مقطع** (ملف `risk_scorecard.json`) يحسب:

| المحور | ماذا يكشف |
| :--- | :--- |
| **reuse** (إعادة الاستخدام) | نسبة تطابق المقطع النهائي مع المصدر الأصلي (مقارنة فريمات بـ dHash) — **أعلى من 70% = خطر "محتوى مُعاد استخدامه"** يهدد الربح أو يسبب Claim حقوق |
| **first7s** (الربحية) | وجود كلمة مخالفة في **أول 7 ثوانٍ** = إعلانات محدودة |
| **visual** (بصري) | أشرطة سوداء (مظهر منقول) + جاهزية لفحص نموذج محلي للصور |
| **overall** | المستوى الكلي: low / medium / high / danger |

**بوابة النشر**: `--risk-gate warn` (افتراضي) يحذرك ويكتب `publish_blocklist.json` بقائمة المقاطع الممنوعة من النشر؛ و`--risk-gate block` يوقف المعالجة نهائياً عند وجود مقاطع خطرة. يدوياً: `python scripts/risk_scorecard.py --project tmp/مشروعك --exit-on-blocked`.

## ⚠️ دليل عملي: كيف تتجنب مشكلة "المحتوى المُعاد استخدامه"؟

يوتيوب يوقف الربح (وأحياناً يقبل Claims) على المقاطع **غير المحوّلة** — أي قصّتها كما هي بدون إضافة. لحماية قناتك:

1. **لا تنشر مقطعاً "خاماً" من المصدر** — أي مقطع تتجاوز نسبة تطابقه مع المصدر 70% ممنوع. الأداة الآن تكشف هذا بنفسها.
2. **حوّل المحتوى دائماً** (هذا هو معيار يوتيوب الفعلي):
   - ترجمات حية (ViralCutter يضيفها ✅)
   - قص/زوم ديناميكي على الوجوه (مفعّل ✅)
   - **تعليق صوتي أو تحليل خاص بك** فوق اللقطات (الأقوى — افعله خارجياً أو عبر أداة تسجيل)
   - مقطع Intro/Outro خاص بقناتك + علامة مائية (شعارك)
3. **لا تقص المصدر نفسه عدة مرات** — تكرار نفس المصدر في مقاطع كثيرة = إشارة "مُعاد استخدامه" حتى مع التحويل.
4. **قصّر المقاطع** (15-45 ثانية) — المقاطع الطويلة الخام أكثر عرضة للـ Claim.
5. **اختر مصادر قابلة للاستخدام**: فيديوهاتك أنت، محتوى Creative Commons، أو فيديوهات بتصريح واضح. المحتوى التجاري (أفلام، قنوات إخبارية) = خطر Claim شبه مؤكد.
6. **أضف سياقاً تعليمياً/تعليقياً** — يوتيوب يسمح بالاقتباس مع تعليق/نقد، وليس النسخ المجرد.
7. **تجنب اللقطات المحورية للمصدر** (المشاهد "التي لا تُنسى") — يوتيوب يتتبعها بدقة.

> الأداة تساعدك بـ: درجة التطابق (reuse score) لكل مقطع + قائمة `publish_blocklist.json` بالمقاطع الممنوعة — لكن **قرار "كيف أحوّل المحتوى" يبقى عليك**، والدليل أعلاه هو خلاصة ما تطلبه يوتيوب.

**من سطر الأوامر**:

```bash
# حذف المقاطع المخالفة (افتراضي)
python main_improved.py --url <URL> --safety-mode block

# كتم الكلمات المخالفة بدل حذف المقطع
python main_improved.py --url <URL> --safety-mode censor

# تعطيل المراجعة بالذكاء الاصطناعي
python main_improved.py --url <URL> --safety-ai off

# فلترة مشروع موجود بدون إعادة معالجة
python scripts/safety_filter.py --project tmp/MyProject --mode block --in-place
```

> **ملاحظة**: وضع الكتم يحتاج ترجمة بمستوى الكلمة (`input.json` من WhisperX) — أي نسخة صوتية عبر Whisper. إذا استخدمت ترجمات يوتيوب الجاهزة فالكتم يُتخطى تلقائياً (وضع `block` يظل يعمل).

## كيف تبقى قائمة الأمان محدّثة دائماً؟ 🛡️

يوتيوب **لا ينشر قائمة رسمية بالكلمات الممنوعة** — المنع سياقي ومفهومي، لذلك
الحماية طبقات، وليس قائمة كلمات فقط:

| الطبقة | ماذا تفعل | كيف تُحدَّث |
|---|---|---|
| **1. قائمة الكلمات المحلية** (`safety_filter.py` + `safety_blocklist.json`) | تحظر/تكتم الشتائم والتحريض المعروف | كل تثبيت **يسحب الحزمة تلقائياً مرة يومياً** من المستودع (`scripts/safety_updater.py`) — أو زر "تحديث" في الواجهة، أو `python -m scripts.safety_updater --force` |
| **2. مراجعة سياقية بالذكاء الاصطناعي** (`safety_ai.py`) | تلتقط المخالفة **حتى لو الكلمة غير مدرجة أصلاً** (مثل "هؤلاء لا يستحقون الوجود") | بلا تحديث — تعمل بذكاء النموذج نفسه (Gemini/G4F) |
| **3. حلقة الـ Strikes** (`strike_feedback.py`) | تتعلم كلمات المقاطع التي أخذت ضربة فعلاً وتحظرها | `python -m scripts.strike_feedback add --term "..."` أو من الواجهة |
| **4. بوابة الرفع** (`upload_gate.py` + بطاقة المخاطر) | تمنع المقطع الخطير قبل وصوله ليوتيوب نهائياً | بلا تحديث — فحص إجباري قبل أي رفع |

**متى أضيف كلمة جديدة للقائمة الكنسية (لكل المستخدمين):**
1. أضف الكلمة إلى قائمة `BLOCKLIST` في `scripts/safety_filter.py`
2. صدّر الحزمة برقم إصدار جديد: `python scripts/export_blocklist_pack.py --version 2`
3. ادفع إلى المستودع — ويصل التحديث لكل التثبيتات خلال 24 ساعة

**تذكير تلقائي**: سير عمل أسبوعي في GitHub يفتح Issue تلقائياً إذا مرّت 14 يوماً
بلا تحديث، ويغلقه بنفسه عندما يُدفع إصدار جديد.

> ⚠️ واقعي: لا أداة تضمن صفر مخالفات — يوتيوب يقيّم السياق، والمراجعة اليدوية
> للمقاطع مرتفعة الخطورة (المحجوبة في بطاقة المخاطر) قبل الرفع تبقى القرار الأخير.
